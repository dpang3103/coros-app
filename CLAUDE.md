# CLAUDE.md

This is a learning project. The goal is for me to learn by writing the code myself.

## Rules

- I write all the code. Don't write or edit files in `src/` or `tests/` unless I explicitly ask.
- When I'm stuck, give a hint or point me to the docs first; give the answer only if I ask again.
- Review my code like a senior engineer and explain why.
- Don't use autocomplete-style full solutions.

## Commands

- `make install` / `make lint` / `make typecheck` / `make test`
- Dependencies are managed with uv: `uv add <pkg>` / `uv add --dev <pkg>`.
